- Queue tab: the Recent list no longer stops at 20 finished jobs — scroll down and it loads more, so your whole job history stays reachable.
- Fixed renders repeatedly failing with an ffmpeg mux/demux error when your media lives on a network share — a multi-hour render now reads and writes through local disk instead of streaming both directions over the share for hours straight, which is what a flaky share was silently dropping partway through. Only applies when the worker actually has to cross the network for your media; media that's already on local disk (e.g. the worker running on the same machine as your files) is unaffected and renders exactly as before.
- A render now runs at the same time as a subtitle/whisper or a visual scan instead of queuing behind them — it no longer shares that lane, since a render doesn't use the same resources.
- The "staging to local disk" / "copying to the network" steps of a render now show real progress instead of sitting at 0% until they finish.
- Fixed "Running now" showing only one job even when a render and a subtitle/whisper/visual pass were genuinely running at the same time — the other one was wrongly listed under "Up next" as if it hadn't started.
- Fixed the "Add passes" dialog telling you to "approve findings first" for a film you'd already fully reviewed, just because every finding was decided as "leave in" rather than cut. It now says there's nothing to render instead of implying the review was skipped.
- Re-running a pass that already completed ("Done") now actually re-analyzes the film instead of silently handing back the old result — previously it looked like it refreshed, but nothing had actually re-run.
- Fixed queueing a pass sometimes failing with a wrong, misleading "not found under media roots" message (the real cause was usually a slow request timing out) — it now shows the actual reason, and the request gets more time to finish so this shouldn't happen as often.
