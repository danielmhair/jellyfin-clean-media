This installs the Clean Media worker — the local analysis engine that detects objectionable content in your own media, for review inside Jellyfin. Nothing leaves this machine.

Clicking Install will:

  • Install uv (a Python toolchain), FFmpeg, and Ollama with the vision model, if any are missing
  • Set the worker up to run automatically in the background (a launchd service), so there's nothing to leave running

You'll see one macOS password prompt (this installer's own). After that, a Terminal window opens automatically so you can watch progress — it isn't required, just there if you're curious. The whole thing can take several minutes the first time.

The Jellyfin plugin itself isn't included here — that installs from inside Jellyfin (Dashboard → Plugins → Repositories), and this installer prints the exact steps when it finishes.
