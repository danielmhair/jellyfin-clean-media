Installed. If a Terminal window is still open, it's showing the tail end of setup — safe to close once it says it's done.

From then on, a "Clean Media Worker" icon on the Desktop is how you check on it: is it running, restart it, change the media folder or add a second GPU machine, or see recent activity.

Two things left, in Jellyfin itself:

  1. Dashboard → Plugins → Repositories → add:
    https://raw.githubusercontent.com/danielmhair/jellyfin-clean-media/main/manifest.json
    then install Clean Media from the catalogue and restart Jellyfin.
  2. Dashboard → Plugins → Clean Media → set the Worker URL to this Mac's address (e.g. http://<this-machine-ip>:8765) and click Test connection.

If Test connection doesn't succeed right away, give the worker a minute — first start loads the vision model.
